# 🚀 ConsumerConnect

An AI-powered Consumer Complaint Management Platform that enables users to report complaints against companies, interact with other consumers, and receive AI-assisted insights. Companies can respond to complaints through a dedicated dashboard, while administrators manage the platform using comprehensive analytics and moderation tools.

---

## 📌 Overview

ConsumerConnect is a full-stack complaint management platform developed as a final-year project. It leverages Artificial Intelligence to improve complaint handling by automatically predicting complaint categories, estimating severity, detecting spam and duplicate complaints, and estimating resolution time.

The platform provides separate dashboards for Users, Companies, and Administrators, ensuring efficient complaint management and transparency throughout the complaint lifecycle.
